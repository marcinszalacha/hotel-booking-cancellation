# Hotel Booking Cancellation Prediction

End-to-end binary classification project predicting hotel booking cancellations.

## Business objective
Identify bookings at high risk of cancellation while prioritizing precision and maintaining useful recall.

## Methods
- Exploratory data analysis
- Correlation funnel
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
- PyCaret blending and stacking
- Neural network benchmark
- Threshold sensitivity analysis
- Controlled experiment example

## Data
The project uses:
- `data/hotel_cancellations.csv`
- `data/hotel_bookings_geo_experiment.csv`

## Reproducibility
The notebook loads both datasets directly from this GitHub repository.
